Unqlock processes Unqork page content and the current page URL locally in the browser to provide component styling, environment identification and debugging functionality. Appearance and environment preferences, including saved domain groups, are stored in extension-local browser storage. Automatic discovery records visited Unqork hostnames only; it does not save paths, query parameters or page data. Discovery can be disabled and groups can be edited or removed.

Builder panel visibility preferences, custom widths and remembered widths are also stored locally. Module routes are checked in memory to apply preferences on entry; no module-visit history is saved. A page-side adapter receives panel element IDs, bounded widths and the list of panels that must stay collapsed. It invokes native panel methods and temporarily guards expansion while Always collapsed is selected. It does not read or transmit module content.

Unqlock does not use analytics, advertising or tracking services, and does not remotely store or transmit page data. When you choose an environment-switch link, the browser opens the selected hostname with the existing path, query and fragment; review URL parameters before switching. Debug actions may invoke application integrations or save data through the application. Console output remains on the page.

Automatic badges run on HTTPS Unqork subdomains. Custom-domain badges require optional site access, requested only for saved custom hostnames when you choose to enable automatic badges. Grants persist until revoked in browser extension settings; denying access preserves saved mappings. Removing a custom hostname stops its automatic badge registration. Debug tools use temporary active-tab access granted by opening the toolbar popup. Opened from the floating badge instead, Debug tools requests optional site access for that single hostname, only when you choose to enable it; declining leaves the rest of the menu working. No page URL is read through host access the badge does not hold: the page reports its own address to the extension.
